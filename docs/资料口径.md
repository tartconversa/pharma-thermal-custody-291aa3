# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

货物以flow_id表示数量支流。根流在split_at之前持有全部盒数，拆分之后仅由子流持有；同一lot盒数不因重新装箱增加。交接sent/received按transfer_id配对，receive为确认接管时点，未配对及数量差异保留争议。logger读数从at起仅覆盖coverage_minutes分钟，并受装载区间截断；末读不无限延长。子流不自动继承未声明的仪器装载。摄氏与华氏按标准关系转换；上下界含端点。正常与超限覆盖矛盾时记冲突，均超限时按实物时间并集而非仪器数累加。状态区分正常、超限、冲突、未知，未知或冲突不能宣称正常。质量沿物理支流累计经历，责任仅按已确认接管区间计算。time_corrections是后续可单独接收的回执时间补正，不改变拆分实物时点；新时间与拆分矛盾时待核而非偷偷移动拆分。

## lots
药品批及数量。

记录键：['lot_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| lot_id | string | 药批 |
| sku | string | 商品 |
| quantity | integer | 总盒数 |

## flows
物理支流。

记录键：['flow_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| flow_id | string | 支流 |
| lot_id | string | 药批 |
| parent_id | string | 父流 |
| quantity | integer | 盒数 |
| split_at | datetime | 拆分时点 |

## handoffs
独立收发回执。

记录键：['receipt_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| receipt_id | string | 回执 |
| transfer_id | string | 交接 |
| flow_id | string | 支流 |
| side | string | sent或received |
| party | string | 本方 |
| counterparty | string | 对方 |
| quantity | integer | 盒数 |
| occurred_at | datetime | 实际时点 |

## logger_loads
装载证据，不代表所有权。

记录键：['load_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| load_id | string | 装载 |
| logger_id | string | 仪器 |
| flow_id | string | 支流 |
| start | datetime | 开始 |
| end | datetime | 结束 |

## readings
原始测量及覆盖。

记录键：['reading_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| reading_id | string | 读数 |
| logger_id | string | 仪器 |
| at | datetime | 起点 |
| value | number | 温度 |
| unit | string | C或F |
| coverage_minutes | integer | 覆盖分钟 |

## temperature_rules
内部质量口径，不是药品标准。

记录键：['rule_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| rule_id | string | 规则 |
| sku | string | 商品 |
| start | datetime | 生效 |
| end | datetime | 失效 |
| lower_c | number | 下界 |
| upper_c | number | 上界 |

## time_corrections
后续接收的回执补正。

记录键：['correction_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| correction_id | string | 补正 |
| receipt_id | string | 目标 |
| new_at | datetime | 新时点 |
| received_at | datetime | 补正收到 |

同一来源记录键的新文件表示整行修订，调用者明确接收次序；原始文件和接收历史须保留。相同文件摘要不增加事实。下面标为后续接收的文件不随基础资料自动生效，用户可分次装载。历史事实的业务时点与本次接收时点分开。金额除另述外人民币元，结算舍入到分的尾差归该账单分摊基数最大项，并列按业务键升序。本文规定来源语义，不规定待开发仓表、算法或架构。

可用量只指温控证据完整且无冲突未知的量，不替代医学放行。父流拆分之后不能与子流同时计数。质量批次盒时长按数量乘经历时长核对，不能把不同数量支流的时长直接相加当单盒经历。
